# Ave Tenebrae's dependencies. Installation: python3 -m pip install -r requirements.txt
#
# The engine (engine/) and the application (application/) only run with Flask;
# everything else serves the engine or the regeneration of the map.

# --- Runtime: the server and the engine ---
Flask
Werkzeug        # shipped with Flask; imported directly in application/engine/conftest.py

# Discord authentication adds nothing here, and that is deliberate: the session rests on
# `flask.session` (a cookie signed by itsdangerous, which Flask already installs) and the two
# OAuth2 calls on `urllib.request` from the standard library. See application/discord_client.py.

# --- Game persistence (MongoDB) ---
# The todo asked for flask-mongoengine: its last version (1.0.0, 2022) does not import under
# Flask 3 (it looks for `flask.json.JSONEncoder`, removed in 2.3). application/extensions.py
# takes over its interface on top of mongoengine alone.
mongoengine
python-dotenv   # reads the `.env` where the connection details live

# --- Tests ---
pytest
pytest-playwright   # the `page` fixture of the browser engine; then: python3 -m playwright install chromium
mongomock           # MongoDB in memory: the persistence engine require no server

# --- Map regeneration (game_box/extract_map.py, never rerun in practice) ---
Pillow
numpy
scipy
